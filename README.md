# RAG with Weaviate

Проект на Python для ответов по документам с поиском контекста в Weaviate.

## Окружение

Нужен Python 3.11 или новее.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

## Документы

Исходные текстовые документы в кодировке UTF-8 размещаются в `knowledge_base/`.

В репозитории есть пять документов о вымышленной службе доставки «Клён»:
описание сервиса, тарифы, доставка, отмены и поддержка. Все условия и цены вымышлены.
Заголовки обозначаются `#` и `##`, абзацы разделяются пустой строкой.
Текст без заголовков тоже поддерживается.

## Загрузка и разбиение

```bash
.venv/bin/python main.py
```

Программа читает документы, удаляет пустые строки и лишние пробелы, сохраняя
границы содержательных строк. Границы абзацев сохраняются отдельно до очистки.
Программа выводит названия файлов, длину текста и примеры фрагментов с метаданными.
Для другой папки передайте её путь после `main.py`.

`load_documents()` из `loader.py` возвращает список документов с полями
`source_name`, `text` и `paragraphs`.

`chunk_documents()` из `chunking.py` делит документы по разделам. Длинные разделы
делятся по абзацам, предложениям и словам; очень длинное слово — по символам.
Заголовок раздела сохраняется в каждом фрагменте. Размер включает заголовок.
По умолчанию: до 800 символов и до 80 символов перекрытия внутри одного раздела.
У каждого фрагмента есть `document_id`, `source_name`, `chunk_id`, `section_title`
и `text`. Идентификаторы повторяются при неизменных документах и настройках.

```bash
.venv/bin/python main.py --chunk-size 600 --overlap 60 --examples 3
```

## Индексация в Weaviate

Нужен запущенный Docker. База доступна только на локальном компьютере;
данные сохраняются в отдельном томе Docker.

```bash
docker compose up -d
cp .env.example .env
```

В `.env` укажите `OPENAI_API_KEY`, `OPENAI_BASE_URL` и `EMBEDDING_MODEL`.
Для OpenRouter: адрес `https://openrouter.ai/api/v1`, модель
`openai/text-embedding-3-small`. Файл `.env` не включается в Git.

```bash
.venv/bin/python main.py --index --examples 0
```

Программа получает эмбеддинги через API, сохраняет фрагменты, векторы и метаданные
в коллекцию `KnowledgeChunk`, затем читает их обратно и проверяет результат.
Повторная индексация обновляет существующие записи и удаляет устаревшие фрагменты,
в том числе из удалённых документов. Папка документов задаёт полный состав индекса.
Пустая папка не очищает существующий индекс.
При смене модели или сервиса задайте другое имя `WEAVIATE_COLLECTION`.

Остановить базу с сохранением данных: `docker compose down`.

## Проверки

```bash
.venv/bin/python -m unittest discover -s tests -v
```

Проверка повторной записи в запущенную локальную Weaviate (на тестовых векторах):

```bash
TEST_WEAVIATE=1 .venv/bin/python -m unittest discover -s tests -v
```
