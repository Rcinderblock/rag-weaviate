# RAG with Weaviate

Проект на Python для ответов по документам с поиском контекста в Weaviate.

## Окружение

Нужен Python 3.11 или новее.

```bash
python3 -m venv .venv
source .venv/bin/activate
```

## Документы

Исходные текстовые документы в кодировке UTF-8 размещаются в `knowledge_base/`.

В репозитории есть пять документов о вымышленной службе доставки «Клён»:
описание сервиса, тарифы, доставка, отмены и поддержка. Все условия и цены вымышлены.

## Загрузка

```bash
.venv/bin/python main.py
```

Программа читает документы, удаляет пустые строки и лишние пробелы, сохраняя
границы содержательных строк. Она выводит названия файлов и длину очищенного текста.
Для другой папки передайте её путь после `main.py`.

`load_documents()` из `loader.py` возвращает список документов с полями
`source_name` и `text`.

## Проверки

```bash
.venv/bin/python -m unittest discover -s tests -v
```
