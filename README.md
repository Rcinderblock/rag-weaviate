# RAG with Weaviate

Проект на Python для ответов по документам с поиском контекста в Weaviate.

## Окружение

Нужен Python 3.11 или новее.

```bash
python3 -m venv .venv
source .venv/bin/activate
```

## Документы

Исходные текстовые документы в кодировке UTF-8 размещаются в `knowledge_base/`.

В репозитории есть пять документов о вымышленной службе доставки «Клён»:
описание сервиса, тарифы, доставка, отмены и поддержка. Все условия и цены вымышлены.
